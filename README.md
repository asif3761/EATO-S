# EATO'S — GitHub Pages

## Upload
Upload the entire folder contents to the root of your GitHub repository.

## Hero video
Put your licensed MP4 at:

`assets/video/eatos-hero.mp4`

The page already references that path. The site also has an animated visual fallback.

## Before publishing
Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in `robots.txt` and `sitemap.xml` with your actual GitHub Pages address.

## Important
Use only video/images you own or have permission to publish.
